# Mine Helper — прототип 0.2.0

Клиентский мод для **Minecraft Java 1.21.1 + NeoForge 21.1.262**. Выделяй слова и фразы прямо в интерфейсе игры и получай объяснение от GPT на выбранном языке. Выбор текста не открывает новый игровой экран и не ставит мир на паузу.

## Установка

1. Закрой Minecraft.
2. Положи `minehelper-neoforge-1.21.1-0.2.0.jar` в папку `mods` нужного профиля. Дополнительные моды-библиотеки не нужны.
3. Запусти этот профиль и открой мир. Для изучения нужного языка выбери его в Minecraft, например English. Язык объяснений выбирается отдельно в F9.
4. Нажми **F9**. Вставь свой **OpenAI API key**, проверь модель, выбери «Язык объяснений» и нажми «Сохранить».
5. Наведи на предмет, чтобы появилась подсказка. Удерживай **левый Alt**, кликни по слову или протяни выделение по фразе. На отпускании кнопки мыши мод запросит объяснение.
6. Отпусти Alt — управление мышью вернётся в игру. Панель с ответом останется справа.

Ключ создаётся в [настройках OpenAI API](https://platform.openai.com/api-keys). Мод обращается к OpenAI API напрямую; вход в ChatGPT внутри мода не используется. Ключ не нужно присылать в чат.

## Язык объяснений

В F9 доступен переключатель: **AUTO, EN, RU, FR, DE, ES, PT, IT, UK, PL, TR, ZH, JA, KO, AR, HI, ID**. Клик — следующий язык; Shift-клик — предыдущий. Нажми «Сохранить», чтобы применить выбор.

Этот выбор задаёт язык ответа GPT и перевода. Язык выбранного исходного текста определяется автоматически. Например, можно играть на английском, получать объяснения на французском и задавать уточнения на любом языке.

AUTO использует язык Minecraft; для неподдерживаемого языка выбирает английский. Ручной выбор имеет приоритет над языком игры. По умолчанию установлен AUTO, в том числе при чтении старой конфигурации без нового поля. Если хочешь объяснения на русском при английском интерфейсе Minecraft — явно выбери RU.

Ответы в кэше разделяются по языкам. Смена настроек сбрасывает историю текущего обсуждения и отменяет показ старого незавершённого ответа, не создавая нового платного запроса. Для нового объяснения нажми «Объяснить».

Язык интерфейса мода независим от языка объяснений. Надписи интерфейса доступны на английском и русском и следуют языку Minecraft; для остальных языков используется английский интерфейс.

## Управление

| Действие | По умолчанию |
|---|---|
| Выбирать текст и нажимать кнопки помощника | Удерживать левый Alt |
| Выбрать слово и запросить объяснение | Alt + клик |
| Выбрать фразу и запросить объяснение | Alt + протянуть мышью |
| Показать / скрыть боковую панель | F8 |
| Настройки GPT | F9 или Mods → Mine Helper → Config |
| Прокрутить длинный ответ | Alt + колесо над панелью |
| Уточнить ответ | Alt + клик по «Задать вопрос…», затем ввод и Enter |
| Завершить ввод без отправки | Esc |

Клавиши переназначаются в Options → Controls → Key Binds → Mine Helper. Во время ввода вопроса клавиатура вводит текст, мир продолжает работать. Если исходный экран сам ставит игру на паузу, мод не меняет это поведение.

## Что работает

- Выбор слова или фрагмента текста из стандартной 2D-отрисовки Minecraft: чат, названия, меню, книги, подсказки, совместимые интерфейсы других модов.
- Учитываются координаты символов, стили и масштаб интерфейса. Текст помощника исключён из перехвата.
- Подсказка предмета закрепляется при входе в режим выбора: можно перевести курсор с предмета на текст подсказки.
- Выделенная фраза и контекст сохраняются, даже если исходное сообщение уже изменилось.
- Объяснение, перевод, разбор грамматики, уточняющие вопросы.
- Сеть работает в фоне, включая создание HTTP-клиента. Нет запросов на каждом кадре.
- История ограничена тремя парами вопрос/ответ и 5000 символами; выбранный текст — 1200, контекст — 1600, вопрос — 1000 символами.
- До 300 ответов в локальном кэше. Уточнения с историей не кэшируются. Для одинакового текста учитываются контекст, модель, язык ответа и версия промпта.
- Счётчик фактических входных и выходных токенов из ответа API.
- Понятные сообщения об отсутствии ключа, ошибках доступа, лимитах, недоступной модели и сетевых ошибках.

## Подключение GPT

Используется [Responses API](https://developers.openai.com/api/docs/guides/text), адрес `https://api.openai.com/v1/responses`, `store: false`. Отправляется только выбранный текст, ближайший текстовый контекст и короткая история текущего обсуждения. Скриншоты, сохранения мира и весь экран не отправляются. Для этой версии используется текстовый ответ целиком после завершения генерации; посимвольный вывод ещё не реализован.

Модель по умолчанию — `gpt-4.1-mini`. Её можно заменить в F9 на другую доступную в твоём OpenAI API модель с поддержкой Responses API. Не все модели доступны всем аккаунтам. Лимит генерации — 500 токенов; для моделей с внутренним рассуждением может потребоваться увеличить `maxOutputTokens` в настройках.

Локальные файлы в папке профиля:

```text
config/minehelper/settings.json   модель, explanationLanguage, лимит и кэш
config/minehelper/openai.key      API key (обычный локальный текстовый файл)
config/minehelper/answers.json    кэш ответов
```

Вместо файла ключа можно задать переменную окружения `OPENAI_API_KEY` для запуска Minecraft: она имеет приоритет. Пустое поле ключа в F9 сохраняет уже настроенный ключ. Чтобы удалить файловый ключ, удали `openai.key` при закрытой игре. Для очистки кэша удали `answers.json` при закрытой игре.

## Границы первой версии

- Поддерживается NeoForge для 1.21.1; этот JAR не подходит для Fabric, Forge и других версий Minecraft.
- Это прототип, а не обещание совместимости с любым модпаком. Специальная отрисовка, надписи-картинки и 3D-текст в мире (например, таблички) ещё не поддерживаются. OCR нет.
- При сложной композиции разных перекрывающихся интерфейсов выбор текста и группировка соседних строк могут требовать отдельных интеграций.
- Первая версия ориентирована на английский текст слева направо. Двунаправленное письмо и вертикальная отрисовка не проверены.
- API key каждый пользователь вводит сам. Общего сервера и встроенного общего ключа нет.
- Отмена или замена локального запроса не гарантирует, что уже отправленная генерация не будет оплачена провайдером.
- Словарь, произношение и повторение слов пока не реализованы.

## Сборка из исходников

Требуется JDK 21 и доступ в интернет для первой загрузки зависимостей:

```powershell
./gradlew.bat build
```

Готовый JAR: `build/libs/minehelper-neoforge-1.21.1-0.2.0.jar`.

```powershell
./gradlew.bat test
./gradlew.bat runClient
```

Тесты проверяют выделение, Unicode, порядок текста, ограничение истории, кэш и HTTP-протокол через локальный тестовый сервер. Они не расходуют OpenAI API токены. Результаты проверки текущей сборки — в соседнем файле `VALIDATION.md`.

## Устройство исходников

- `text/TextCapture` — текст и координаты символов из отрисовки.
- `text/TextSelection` — выбор слова, фразы и строк.
- `ui/HelperOverlay` — живой слой поверх интерфейса и управление вводом.
- `ui/SettingsScreen` — настройка модели и ключа.
- `HelperSession` — запросы, история, ответы и защита от устаревших результатов.
- `gpt/GptClient` — OpenAI Responses API.
- `gpt/LearningPrompt` — общий промпт с выбранным языком ответа.
- `language/ExplanationLanguage` — коды и названия поддерживаемых языков.
- `assets/minehelper/lang/` — независимая локализация интерфейса.
- `gpt/AnswerCache` — локальный кэш с учётом контекста.
- `mixin/` — точки подключения к тексту, клавиатуре, мыши и подсказкам Minecraft.

Основа сборки: официальный [NeoForge MDK для 1.21.1](https://github.com/NeoForgeMDKs/MDK-1.21.1-ModDevGradle).
